## Objective

Run the epic's exit checks for real, report the numbers that came back, and
name every area where a check was not run rather than reporting a pass that was
never taken.

## Business reason

This is the last gate before a couple's link goes to their family. It is also
the task most likely to be reported green from a distance, and this programme
has already had one cycle of green gates that were red
(`evidence/E05-production-blocker-app-gate.md`, and I-014 on the studio side).

## Intended outcome

Each of the seven named areas has either a command, its real output and a
verdict, or a written statement that it was not tested and why.

## Scope

published workspace at `/p/[slug]` and the Timeline audience publication at
`/s/[token]`.

## Non-goals

- **Performance numbers.** There is no Lighthouse or Web Vitals run in this
  repository's test chain, and `evidence/E08.10-performance-budgets.md` is
  where budgets live. Inventing a number from a local build on one machine
  would be worse than saying it was not measured.
- **Cross-browser.** `experience/playwright.config.ts` sets
  `browserName: "chromium"` for every project. There is one engine. Four
  viewports is not four browsers and this document does not pretend otherwise.
- **Fixing `/p/[slug]`.** The social-preview defect found here is real and its
  fix is one function, but that route is being changed concurrently under
  R-031. Reported with its line, not edited.

## Acceptance criteria

1. **Unpublish** closes the boundary for the same token, and every active share
   is revoked in the same transaction. Proven behaviourally, not by reading.
2. **Broken link** produces a real 404 on both token surfaces, with a page that
   tells the holder what happened without leaking whether the timeline ever
   existed.
3. **Delete and unpublish on `/p`** remove the page, and the window inside
   which that is true is stated as a number rather than assumed to be instant.
4. **Accessibility**: zero critical and zero serious axe violations, and no
   horizontal document overflow, on every published surface at 390, 768, 1280
   and 1440. Reported as counts from a real run.
5. **Social preview**: what unfurls in a message app is checked on both
   products, and any line that reads as product marketing on a couple's wedding
   page is reported against D-011 point 2.
6. Every area not measured is named as not measured, with the reason.
7. No claim in the evidence is stated as a pass without the command that
   produced it and its real output.
