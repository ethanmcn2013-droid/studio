## Objective

Write down the rail rule as an architectural rule with a precise route scope, and cite the enforcement that already exists.

## Business reason

## Intended outcome

The rule is stated with route families, the meaning of rail-free beyond the rail itself, and what is enforced versus what is convention.

## Implementation approach

Audit the shipped chrome, state the rule at route-family granularity, and separate what a test enforces from what is currently only convention.

## Acceptance criteria

1. Route families that carry the rail and route families that must not are both named.
2. Rail-free is defined to include the metadata surface, not only the visual rail.
3. The existing executable enforcement is cited by file.
4. Anything unenforced is named as convention rather than as a rule.
