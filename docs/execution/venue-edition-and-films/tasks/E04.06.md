# E04.06 — Implement venue-workspace unlinking without removing or exposing the couple’s private work.

**Epic:** E04 — Venue Edition product architecture and workspace lifecycle

## Objective

Define the sponsorship axis as separate from the access axis and prove in code that unlinking cannot touch the couple's access.

## Business reason

D-020 point 2 is a promise made in writing to every founding venue and D-020 point 3 is a promise to every couple. Both are only real if the code cannot break them.

## Intended outcome

A sponsorship transition provably leaves the access state where it was, for every combination of state and event, and branding removal has a checkable 24-hour deadline.

## Deliverables

- [ ] studio/src/lib/venue-lifecycle.ts SPONSORSHIP_STATES, nextSponsorshipState, sponsorBrandingVisible, accessAfterSponsorshipEvent, brandingRemovalDeadlineMs
- [ ] studio/src/lib/venue-lifecycle.test.ts the survival invariant, tested across every state and event combination
- [ ] studio/docs/architecture/ADR-008-venue-edition-lifecycle.md section 6

## Scope

The sponsorship state machine, the survival invariant, the branding-visibility rule and the removal deadline.

## Non-goals

The unlink UI. The 24-hour removal job. Writing workspaceSponsorships transitions into the app. The mechanism is defined and proven here; wiring it to a button is E07 and E05.

## Dependencies

| Dependency | State | Waived? |
|---|---|---|

## Inputs

app/src/server/db/schema.ts workspaceSponsorships, studio/src/lib/entitlements-db/sponsorship-policy.ts, D-020 points 2 and 3.

## Implementation approach

Express the survival promise as a function whose behaviour is asserted exhaustively, so that a future change which breaks the promise fails a test rather than reaching a venue.

## Acceptance criteria

1. Sponsorship and access are separate state axes with separate transition tables.
2. No sponsorship event changes the access state, asserted for every state and event pair.
3. A lapsed licence stops new issuance and nothing else.
4. Venue branding is visible only while the sponsorship is active.
5. Branding removal carries an explicit 24-hour deadline from release.
