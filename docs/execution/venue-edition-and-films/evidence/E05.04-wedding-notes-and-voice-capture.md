### 1d. What the wedding signal actually is, and what it is not

This corrects a plausible-looking wrong turn. `TasksWorkspaceDestination`
already carries `contextType` and `primaryDate`
(`src/modules/notes/server/tasks-personalization.ts:21-23`), so `contextType`
looks like the wedding signal. **It is not**, on the path a sponsored couple
actually takes:

- `src/server/db/ensure-user.ts:79-99` provisions the couple's workspace with
  planning period `context_type = 'general'` and workspace
  `context_type = 'project'`.
- `src/server/actions/comp.ts:259-264` then sets **only** `template_id` and
  `active_domain = 'wedding'`. It never touches `context_type`, and never
  touches the planning period.

So `contextType` stays `'project'` for a redeemed couple. The only wedding
signal on the row is `active_domain`.

### 1e. The seam that made this cheap

`src/app/api/internal/workspace-personalization/route.ts:98` already returns
`activeDomain`. Notes already has a client for that route,
`fetchTasksPersonalization` (`tasks-personalization.ts:233`), which had **zero
callers** and dropped the field because its return type did not declare it.

**No new route, no new field, no migration.** Criterion 5 is met by declaring a
field that was already on the wire.

## 2. The finding this task exists for

**Dictation sends a couple's private planning speech to a third party, and
nothing told them.**

`useVoiceCapture` uses the browser's `SpeechRecognition`. In the engines that
implement it, recognition is a network service run by the browser maker, not an
on-device computation. The audio leaves the device.

Searched for any disclosure:

```
grep -rni "speech|dictat|microphone|voice" src/app/privacy/page.tsx src/app/terms
  → only a code comment about brand "voice" at privacy/page.tsx:15
grep -rni "speech recognition|web speech|dictation|microphone" docs *.md
  → no matches
```

**Zero disclosure in the product, the privacy page, or any document.**

That is a genuine exposure for a programme whose central promise is privacy,
and it is worse in this context than in general: the notes a couple dictates
are about money, family and guests, and the guests consented to nothing. It
sits beside R-017 rather than inside it. **Raised as a new RAID candidate.**

The prior audit (`evidence/E05-E06-audit.md`) did not examine voice capture at
all. This extends it; it does not contradict it.
