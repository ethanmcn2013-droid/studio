# Adversarial fact-check of BRIEF.md version 1.0

Run 2026-08-03 by an independent agent instructed to be hostile, against primary
sources only. **95 discrete factual claims checked. 14 wrong or materially
misleading. 81 confirmed. 0 unverifiable.**

Recorded because the brief is the document every later session and venue-facing
asset copies its facts from. A wrong number in it propagates into a signed
contract, and "it looked right" is how that happens.

All fourteen are fixed in version 1.1. A second pass was run against the
correction.

## The navigation hazard it found

The brief told sessions that `DECISIONS.md` outranks it. **D-003, D-004, D-005
and D-006 still carry the header "proposed, founder decision required" despite
being resolved by D-009, D-010, D-020 and D-015 Q4.** A session obeying the
precedence line would have found four entries demanding founder decisions on
price, access term, entitlement and naming, all settled, and the brief gave it no
warning.

Fixed by the index added to `DECISIONS.md` for E01.08, and by a warning at the
top of the brief.
