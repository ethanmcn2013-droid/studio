## 3a. What this section teaches, and it is the point of the whole ledger

A file-by-file claim about a live working tree has a shelf life measured in
minutes when four sessions are running. This ledger asserted "verified by grep,
not inherited from an earlier session's notes" and then carried two rows that its
own grep never produced.

**The rule that follows: never state a repository fact in a document without
re-running the check in the same minute you write it, and never describe a live
tree as though it were a fixed artifact.** §4's commands exist so the next reader
can regenerate this rather than trust it.
