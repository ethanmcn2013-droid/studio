## 1. Write the test against the product that exists

The task title says "live Venue Portal". **There is no venue login.** Verified
2026-08-04:

- `src/lib/account/live/project-venue-access.ts:330` returns `members: []`
  unconditionally.
- `src/lib/hq/auth.ts` is one shared password in front of the whole `/hq`
  surface. It was hardened on 2026-08-03 (v2 HMAC token, PBKDF2-derived key,
  server-side expiry) and its own header states what it still is not: *"It is a
  shared password. There is no per-person identity, no venue account, no
  revocation of one holder without rotating for everyone, and no audit trail
  that can attribute an action to a named person."*

So this script tests Option C from `evidence/E07.16-venue-identity-lab.md`, which
is the recommended launch position: **Signal HQ administers, the venue receives
evidence.** A test written against a login that does not exist would pass
nothing and prove nothing.

**Operational hard rule.** The HQ password also opens Today, Money, Company,
Vault, Atlas, Decks, Founders Circle and the Data Room. It is never given to a
venue, for any reason, including "just to look".

## 2. The second thing to get straight: the report is HTML

`src/app/hq/account-review/download/route.ts`, live path, verified 2026-08-04:

- accepted formats are `csv` and `html` only; anything else returns 404;
- the report branch calls `snapshotToReportHtml` and returns
  `Content-Type: text/html; charset=utf-8` with a `.html` filename.

`pdfFilename` is imported into the route but the live branch never emits a PDF.
**Nothing venue-facing may call this a PDF.** Either produce a real PDF or call
it a report. Saying PDF and sending HTML is a small lie that a venue notices the
first time it tries to attach it to something.

### Step 2 — Confirm the small-cell test is two-sided (R-027)

- **Run:**
  ```bash
  grep -n -A4 "export function isSmallCell" _wt-wp22/src/lib/account/instrumentation/suppression.ts
  ```
- **Expect:** the function withholds when the value is below the floor **and**
  when the complement is.
- **Result 2026-08-04:** **PASS.**

  ```
  export function isSmallCell(value: number, population: number): boolean {
    if (value < BEHAVIOURAL_MIN_WORKSPACES) return true;
    return population - value < BEHAVIOURAL_MIN_WORKSPACES;
  }
  ```

  The module's own comment states the rule this closed: *"publishing '3 of 5'
  also publishes '2 of 5 did not', and the second sentence is the one that
  identifies people"*, and *"A message that says 'fewer than three' is itself the
  disclosure the floor exists to prevent."* R-027 as recorded is closed in this
  branch.

### Step 3 — Confirm the rate threshold now runs (R-028)

- **Result 2026-08-04:** **PASS.** `daily-metrics.ts:238,241` call `presentRate`.
