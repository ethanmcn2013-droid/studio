## 1. The audit: the flow exists, and it is well built

The task title says "complete the promotion flow". The flow is not missing. It
is one of the more carefully engineered things in the repo:

| Capability | Where |
|---|---|
| Exact-body-bound cross-product assertion (v2, SHA-256 of the approved body inside the signed envelope) | `src/modules/notes/server/notes-cross-product-assertion.ts:79` |
| Duplicate protection with an exact-retry lock | `HybridNotebook.tsx` `extract.immutableRetry` |
| Conflict detection when the note changed mid-send | `src/modules/notes/lib/notes-hybrid.ts`, tested |
| Offline queueing and local recovery | `HybridNotebook.tsx`, `recoveryScope` namespaced by a SHA-256 of the account |
| A stated payload boundary shown to the user | the panel's `payloadReceipt` line |

**So the gap was never the mechanism. It was the words.**

## 7. Behaviour is unchanged

Every hunk in the hand-off region is a string substitution. No state variable,
no guard condition, no server action, no assertion and no retry path was
edited. The three structural changes are:

1. `copy` derived once at the top of the component from a new optional prop.
2. `voice.engine` added alongside the existing `voice.supported`, which is now
   `engine === "ready"`. Same boolean, same call sites.
3. The task id moved from prose into `data-task-id`.

`notes-hybrid.test.ts` (the flow's behaviour tests: approved payloads, version
conflicts, selection validation) passes unchanged, as does
`timeline-promotion.test.ts`.

## 8. What is NOT done

- **The local-recovery and offline strings are untouched.** Roughly fourteen of
  them, including "Local recovery is blocked. Your exact words remain in the
  editor; keep this tab open and reconnect before leaving." They are as
  engineer-shaped as anything this task fixed. They belong to a different
  subsystem, and rewriting them well needs a decision about what the product
  promises when a device cannot hold a spare copy, which is a behaviour
  question wearing a copy costume. Named, not skipped.
- **The Timeline preview panel** inside the note detail still reads "Title",
  "Completion", "Named audience". That panel is E05.08's surface.
- **The legacy `Notebook.tsx`** got only its two genuinely wrong strings fixed
  (`aria-label="Promote note"`, and "Signal Tasks" which violates the naming
  contract in `docs/SUITE_URL_AND_NAMING_CONTRACT.md`). Its remaining wording
  was already close, and it is reachable only by setting
  `NOTES_LEGACY_NOTEBOOK_ENABLED=1`.
- **No human has read these strings on a rendered screen.** They are verified
  by test and by diff, not by eye, and not at any breakpoint.
