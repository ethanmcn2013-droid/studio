## Two honest limitations of how this wave was run

**1. File ownership inside a package was convention, not enforcement.** Each package had
one worktree shared by its build groups, so several agents wrote in the same tree
concurrently. Gate colour observed *during* the run is therefore not trustworthy. The
mitigation is that every gate was re-run after the wave settled — `pnpm test` exit 0 on
`_wt-wp08` by me directly, and by the verifiers on the other two. Next wave should give
each build group its own worktree, not each package.

**2. Two tasks were force-stopped rather than forced through.** E12.05 and E12.14 are
built, verified and evidenced, but depend — directly or via E12.05 — on **E05.12**, the
design-system review, which is founder-creative and deliberately outside Wave 3. The tool
refused the transition. I did not use `--waive-deps`, because a dependency waiver is your
consent and I will not invent it. They are recorded as blocked, with the unblock path.
