The approved programme delegates this engineering decision. Studio owns verified
venue eligibility and an immutable exact code allocation. App owns a bounded,
authenticated issuance/readback/withdrawal service and retains its existing
atomic comp claim as the positive grant writer. Studio receives no broad App
database credentials. Usage authentication cannot authorize issuance.

The current standard/Founding annual prices remain €1,500/€1,000 VAT-inclusive.
A paid-plan selection is not cash. New allocation requires current verified
payment and its local mirror, or an explicit current limited pilot exception.
An earlier valid allocation can recover after the venue term ends without
shortening an existing couple grant. Event purchase/refund policy is separate.

All code delivery is pending until exact destination acknowledgement and a
subsequent readback are retained. A manual packet is prepared only after that
receipt commits. Withdrawal cannot revoke a claimed grant. Historical codes need
observed original provenance before attribution; a new hash is not evidence.

The additive shared ledger and local three-store tests are implementation
evidence. They do not establish a deployed configuration, cleared payment,
provider rehearsal, public readiness or outreach authority. First persisted
deliberate use is recorded separately from issuance and redemption. The guide
contains recovery boundaries and exact test registrations; the programme index
and acceptance ledgers remain with their owners.
