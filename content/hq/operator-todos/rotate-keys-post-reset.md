Turso tokens are reissued automatically by the reset (new databases, new
tokens). Everything below lives in a dashboard only the founder can open.
The working session updates Vercel/GitHub the moment each new value exists —
do these in one sitting with the session active.

## Steps — do first (values were exposed in plaintext on disk)

1. **Slack** — api.slack.com/apps: both bot identities (Directors and
   Advisors). The bot is retired, so *revoke/delete the apps* rather than
   rotating. The local `.env` files holding their tokens are deleted in the
   demolition pass.
2. **Anthropic** — console.anthropic.com → API keys: revoke the two keys the
   Slack bots used. (The app's own AI features are unprovisioned in prod —
   nothing else breaks.)
3. **Signal HQ password** — pick a new one; the session sets
   `SIGNAL_HQ_PASSWORD` in Vercel + the studio repo's Actions secret.

## Steps — with the cutover

4. **Clerk** — dashboard.clerk.com: rotate the secret key; recreate both
   webhook endpoints (`app.signalstudio.ie/api/webhooks/clerk` and the
   studio GDPR receiver) and hand the session the two new signing secrets.
   While there: delete any leftover apps from the four-app era and confirm
   only “Signal Studio” remains.
5. **Stripe** — dashboard.stripe.com: roll the secret key, recreate the
   webhook endpoint against `app.signalstudio.ie/api/webhooks/stripe`, and
   create the three missing prices (Workspace annual, Studio monthly,
   Wedding one-time) so all five `STRIPE_PRICE_*` vars are real. Confirm
   test vs live mode is what you intend pre-launch.
6. **Resend** — resend.com: fix the sender state for `hello@signalstudio.ie`
   (the open P1 says production sends are rejected), then issue one new API
   key and delete any legacy keys from the analytics era.
7. **Vercel** — account settings → tokens: roll the token stored as the
   studio repo's `VERCEL_TOKEN` Actions secret (deck publishing).
8. **Turso** — revoke the `stack-reset-2026-07-31` platform token once
   Phase 6 is done.

Internal shared secrets (CRON_SECRET, cron-ping pair, NOTES_TO_TASKS,
OUTBOX_DELIVERY, SUITE_API_KEY, STUDIO_OPS, STUDIO_MIGRATE, PARTNER_STATS)
are regenerated by the session — no dashboard needed.
